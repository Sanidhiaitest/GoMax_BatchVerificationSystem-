Drop product photos here, one per formulation, named by its CODE
(lowercase, spaces -> hyphens, keep existing hyphens as-is):

  Code in the app        ->  filename here
  -----------------------    -------------------
  P20                    ->  p20.png
  GROUT-2                ->  grout-2.png
  ROCKCRETE-280          ->  rockcrete-280.png
  SUPFLOOR-100           ->  supfloor-100.png

Grey / White variants have their own codes (e.g. "PURETILE-GREY",
"PURETILE-WHITE"), so give each its own file:

  puretile-grey.png
  puretile-white.png

PNG or JPG, roughly square or a bit tall (the card crops to fill a
100px-wide panel). Any product without a file here falls back to the
coloured swatch with its code initials — so you can add these one at a
time, no code change or rebuild needed.

Not sure of a product's exact code? Open the Admin Dashboard -> Products
(or Formulations) list; the code is shown on every row. Use that string,
lowercased.
